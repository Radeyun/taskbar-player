# Taskbar Player

Маленькое приложение для Windows 10: показывает текущий трек на панели задач, рядом с областью
уведомлений, и даёт кнопки для управления плеером.

![Taskbar Player на панели задач](docs/screenshot.png)

[English version](README.md)

- Показывает **Исполнитель — Трек**: Spotify, браузер, любой плеер, который виден в системной
  медиапанели Windows. Если играют несколько, приоритет у Spotify.
- Кнопки **⏮ ⏯ ⏭** прямо на таскбаре.
- При переключении трека название уезжает влево или вправо.
- Подстраивается под тему таскбара (светлая/тёмная) и масштаб DPI.
- Без аккаунта Spotify, ключей API и логинов: данные берутся из системных медиаконтролов (GSMTC).
- Около 80 КБ, один exe, больше ничего ставить не нужно. В простое почти не нагружает процессор.

## Установка

1. Скачайте `TaskbarPlayer.exe` из [последнего релиза](../../releases/latest).
2. Запустите и нажмите **Yes** в окне «Install Taskbar Player?».

Готово. Приложение скопирует себя в `%LOCALAPPDATA%\Programs\TaskbarPlayer`, запустится и дальше будет
стартовать вместе с Windows. Права администратора не нужны.

> **SmartScreen** может показать «Система Windows защитила ваш компьютер», потому что exe не подписан.
> Нажмите **Подробнее → Выполнить в любом случае**.

**Обновление:** скачайте новый `TaskbarPlayer.exe`, запустите и нажмите **Yes**. Запущенная копия
заменится и перезапустится.

**Удаление:** ПКМ по плашке → **Uninstall**.

**Без установки:** нажмите **No** в окне установки (или запустите с `--portable`). Тогда exe просто
работает с того места, где лежит.

## Управление

| Действие | Что происходит |
|---|---|
| Кнопки ⏮ / ⏯ / ⏭ | Предыдущий трек / пауза-воспроизведение / следующий трек |
| ЛКМ по названию | Копирует «Исполнитель — Трек» в буфер обмена (на секунду появляется «Copied») |
| СКМ | Пауза / воспроизведение |
| Колесо вверх / вниз | Следующий / предыдущий трек |
| ПКМ | Меню: Pause/Play, Next track, Previous track, Copy, Start with Windows, Uninstall, Exit |
| Наведение | Подсказка с полным названием |

На паузе название приглушено. Если ничего не играет, на плашке «—».

Анимация запускается, только если трек действительно сменился. Если «предыдущий» просто перемотал
песню в начало (Spotify так делает после первых ~3 секунд), название остаётся на месте.

## Требования

- Windows 10 версии 1903 или новее, горизонтальный таскбар на основном мониторе.
- .NET Framework 4.8, который уже встроен в Windows 10 1903+.

В Windows 11 другой таскбар. Там приложение должно переключиться на окно поверх таскбара, но это не проверено.

## Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--width=300` | Ширина области названия в пикселях при масштабе 100% (по умолчанию 260; три кнопки добавляют 90) |
| `--font="Segoe UI"` | Шрифт названия (по умолчанию `Segoe UI Semilight`, по толщине как часы на таскбаре) |
| `--gamma=1.0` | Толщина текста на тёмном таскбаре: меньше — тоньше (по умолчанию 1.4) |
| `--portable` | Никогда не предлагать установку |
| `--log` | Писать диагностику в `%LOCALAPPDATA%\TaskbarPlayer\error.log` (падения пишутся туда всегда) |
| `--fallback` | Не встраиваться в таскбар, а показывать окно поверх него |

Чтобы передать параметры при автозапуске, отредактируйте значение `TaskbarPlayer` в
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`.

## Сборка из исходников

Нужен [.NET SDK](https://dotnet.microsoft.com/download) (8 или новее) или Visual Studio 2022.

```bash
dotnet build -c Release
```

Exe появится в `bin\Release\net48\TaskbarPlayer.exe`. При пуше тега `v*` GitHub Actions собирает его
и прикладывает к релизу (см. [.github/workflows/build.yml](.github/workflows/build.yml)).

## Как это устроено

- **Встраивание** работает как в [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor):
  `Shell_TrayWnd → ReBarWindow32 → MSTaskSwWClass`. Список кнопок окон сужается на ширину плашки, а плашка
  становится дочерним окном `Shell_TrayWnd` в освободившемся месте. Когда таскбар сам перекомпоновывается
  (новый значок в трее, смена разрешения), WinEvent-хук и таймер раз в секунду сужают список заново.
  При выходе исходная ширина возвращается.
- **Запасной режим:** если встроиться не удалось, слева от `TrayNotifyWnd` появляется окно без рамки
  поверх всех окон. Над полноэкранными приложениями оно скрывается.
- **Перезапуск explorer.exe** обрабатывается через сообщение `TaskbarCreated`.
- **Данные о треке** приходят событиями `Windows.Media.Control`. Опрос раз в 2 секунды только страхует.

## Ограничения

- Только основной монитор и горизонтальный таскбар. С вертикальным таскбаром плашка скрывается.
- Колесо мыши работает, если включена настройка «Прокручивать неактивные окна при наведении на них»
  (в Windows она включена по умолчанию).
- Текст сглаживается в оттенках серого: ClearType на прозрачном фоне невозможен.
- Если процесс убить (диспетчер задач, `taskkill /f`), кнопки окон останутся суженными до следующей
  перекомпоновки таскбара. Выходите через **Exit** в меню.
